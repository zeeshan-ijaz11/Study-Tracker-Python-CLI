# 📚 Study Tracker – Python CLI

A simple and beginner-friendly **Python Command-Line Study Tracker** that helps you record study sessions, track your learning time, and monitor your daily study progress.

## ✨ Features

- ➕ **Add Study Sessions** – Record a subject and the time you spent studying.
- 📋 **View Study Sessions** – Display all your recorded study sessions.
- 📊 **Daily Summary** – Check your total study time and daily progress.
- 🎯 **Daily Study Goal** – Track your progress toward your daily study target.
- 💾 **Simple Data Management** – Organize your study records.

## 🛠️ Technologies Used

- Python 3
- Lists and Dictionaries
- Loops and Conditional Statements
- Basic Input and Output

## 📂 Project Structure

```text
study-tracker/
└── main.py
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd study-tracker
```

### 3. Run the application

```bash
python main.py
```

The goal of this project is to practice Python fundamentals by building a practical application that makes tracking study habits simple and organized.
